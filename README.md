# Bright Future Academy 🎓

A responsive school website built as my **Week 1 project** during the **Moat Academy Software Development Bootcamp**.

## 📖 About the Project

**Bright Future Academy** is a fictional school website designed to provide students, parents, and visitors with information about the school, its courses, admission process, and other activities.

This project was created as part of my first week of practical training at Moat Academy, where I focused on learning the fundamentals of building websites with HTML and CSS.

## ✨ Features

- 🏠 Home page with a welcoming hero section
- ℹ️ About section/page
- 📚 Courses section
- 🖼️ Gallery
- 📝 Admission page
- 📞 Contact page
- 🔗 Navigation between different pages
- 📱 Responsive layout

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📚 What I Learned

Through this project, I practiced:

- Structuring web pages with HTML
- Creating navigation menus
- Working with images
- Using links and file paths
- Creating forms
- Organizing website content
- Styling web pages with CSS
- Building a multi-page website

## 🎯 Project Goal

The goal of this project was to apply the foundational web development concepts I learned during Week 1 and turn them into a complete, functional school website.

## 🖥️ Website Pages

The website includes:

- **Home** — Introduction to Bright Future Academy
- **About** — Information about the school
- **Courses** — Available courses/programs
- **Gallery** — School-related images
- **Admission** — Admission information/application
- **Contact** — Contact information and form
